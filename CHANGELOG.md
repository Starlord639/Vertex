# Changelog

All notable changes to Vertex are documented in this file.

## [0.2.0] - 2026-09-08

### Changed

- Replaced the separate Sessions, Explorer, and Changes navigation with two fixed top-level tabs: Chat and Workspace.
- Moved Explorer and Changes into the Workspace tab.
- Added a conversation-only Chat mode that uses read-only access, disables plan/build controls, blocks approval requests, and instructs models not to modify workspace files.

## [0.1.0] - 2026-09-07

### Added

- Initial Vertex desktop application for working with multiple coding-agent providers.
- Windows x64 application and NSIS installer builds.
- Integrated code editing, terminals, source control, file navigation, sessions, notes, search, and agent tools.
- Support for Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, omp, and fx.

### Changed

- Established Vertex as the product name across the interface, application metadata, packages, runtime identifiers, storage keys, events, tests, documentation, and release tooling.
- Set the application version to `0.1.0` for the first Vertex release.
